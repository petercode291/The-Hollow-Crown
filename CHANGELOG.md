# Changelog

## 1.0.0 — Initial browser edition

- Created a responsive dark-fantasy web interface for The Hollow Crown.
- Added five playable classes and class-specific abilities.
- Implemented turn-based combat, status-effect processing, dungeon rooms, bosses, loot, XP, upgrades, relics, and achievements.
- Added three local save slots, schema validation, settings, and seeded random state persistence.
- Added Node-based regression tests and GitHub Pages deployment workflow.
- Documented setup, architecture, game design, and contribution guidelines.
